- Các bước cài đặt bản cài 04:
B1: Tải file cài đặt và Script update tương ứng với đơn vị CSDT, giải nén file CSDT_V04.rar, bên trong sẽ bao gồm 
+ bộ cài: GPLX-CDB-CSDT-v1004-030926.msi 
+ file script: 030926-Script-Update-Database-CSDT.sql

B2: Tạo bản backup database CSDT hiện tại để lưu trữ dữ liệu backup nếu có vấn đề cập nhật

B3: Kết nối với SQL server với tài khoản đăng nhập SQL server của đơn vị, truy cập database của CSDT
+ chọn database của CSDT, bấm New Query
+ copy nội dung trong file script 030926-Script-Update-Database-CSDT.sql, dán vào cửa sổ New Query 
+ bấm excute query và đợi, chỉ thành công khi thấy trạng thái tích xanh: success

B4: Gỡ cài đặt phần mềm các phiên bản cũ

B5: Chạy cài đặt bộ cài GPLX-CDB-CSDT-v1004-030926.msi, bấm next đến khi hoàn thành cài đặt 

B6: Cấu hình bộ cài mới luôn chạy với quyền Administrator (để có quyền đọc/ghi ảnh)

B7: Mở phần mềm và chỉnh sửa thông tin kết nối database có sẵn và chỉnh sửa đơn vị cài đặt 
(có thể thay thế lấy file config cũ FPT.GPLX.exe.Config trong bộ cài cũ cũng được, vì file config này lưu thông tin kết nối database và đơn vị đăng nhập cũ đều được)
	
B8: Yêu cầu kiểm tra lại đường dẫn ảnh trong tham số hệ thống 
Vào Quản trị hệ thống > Quản lý tham số hệ thống > Tìm giá trị "IMG_PATH_CSDT" và chỉnh sửa đường dẫn ảnh đúng theo đơn vị CSDT đang sử dụng
